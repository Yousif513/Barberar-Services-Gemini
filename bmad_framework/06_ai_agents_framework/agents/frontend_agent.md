### 1. Responsibilities:
- Build the responsive landing page, search panels, and reservation screens.

### 2. Inputs:
- UI designs, component requirements, Brand assets, and API routes.

### 3. Outputs:
- React/Next.js responsive web codebases and web builds.

### 4. Work Flow & Handovers:
- Hand over completed web applications to the QA Agent and DevOps Agent.

### 5. Performance Test:
- Verify that pages render correctly on mobile browsers and load under 1.5s on local 4G connections.

# AI Agent Skill Matrix

This matrix details the purpose, required skills, and core responsibilities for all 14 specialized AI agents in our BMAD ecosystem.

---

## Agent Skill Matrix

| Agent Name | Primary Purpose | Required Skills | Primary Deliverable |
| :--- | :--- | :--- | :--- |
| **1. Strategy Agent** | Plan business structure & monetization | Market sizing, competitor SWOT, financial modeling | Pitch Deck & Validation Plan |
| **2. Product Manager Agent** | Define product features & priorities | PRD writing, user stories, roadmapping, prioritization | Master PRD & Roadmap |
| **3. UX Research Agent** | Plan user journeys & pain points | Personas, customer journeys, workflow wireframe mapping | Customer Journey Map |
| **4. UI Design Agent** | Layout visual interfaces & screens | Figma, component libraries, typography hierarchy | Screen Layout Briefs |
| **5. Brand Identity Agent** | Establish brand assets & guidelines | Brand guides, palette design, tone of voice documentation | Typography & Color Specs |
| **6. System Architect Agent** | Map system topology & services | Cloud patterns, API integrations, infrastructure design | System Architecture Doc |
| **7. Database Agent** | Design data model & constraints | PostgreSQL, relational schemas, indexing, triggers | SQL Schema Scripts |
| **8. Backend Agent** | Implement database & server engines | Supabase, Edge functions, API gateways, webhooks | API Endpoints & DB Code |
| **9. Frontend Agent** | Implement Web / Dashboard interfaces | React, Next.js, HTML/CSS, dashboard frameworks | Provider & Admin Dashboards |
| **10. Mobile App Agent** | Build client native applications | React Native / Flutter, push alerts, native maps | Client Mobile Apps |
| **11. QA Agent** | Run testing & integration checkouts | Test case writing, automated scripts, manual UAT | QA Checklists & Test Reports |
| **12. Security Agent** | Audit database protection & access | PostgreSQL RLS policies, encryption, PDPL audits | RLS Policy Scripts |
| **13. DevOps Agent** | Configure CI/CD, Git, and environments | Git hooks, Vercel deployments, Supabase migrations | CI/CD YAML & Git Hooks |
| **14. Growth Agent** | Plan marketing & customer loops | SEO optimization, campaign building, social templates | Acquisition Strategy |

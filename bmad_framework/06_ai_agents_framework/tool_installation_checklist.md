# Tool Installation Checklist

This checklist outlines the tools, environments, and SDK integrations required to run the development pipeline.

---

## Required Tool Matrix

### 1. Development Environment & IDEs
* [ ] **Cursor** or **Windsurf**: Primary AI-native IDEs to execute code suggestions.
* [ ] **Git**: Version control CLI.
* [ ] **GitHub**: Set up organization repository, branch rules, and issue trackers.

### 2. Frontend & Mobile SDKs
* [ ] **Node.js (v18+)** & **npm/pnpm**: Package managers.
* [ ] **React Native Expo CLI** (or Flutter CLI): For building cross-platform native iOS & Android applications.
* [ ] **Vercel CLI**: For deployment and hosting of Next.js responsive web app.

### 3. Backend & Database
* [ ] **Supabase CLI**: For local development, running database migrations, and testing Edge functions.
* [ ] **PostgreSQL Client** (DBeaver or pgAdmin): Visual database explorer.

### 4. Integration APIs & Gateways
* [ ] **Tap Connect / Moyasar SDK**: Saudi-localized payment API integration.
* [ ] **Twilio WhatsApp API / Unifonic**: OTP and transactional communication.
* [ ] **Firebase Cloud Messaging (FCM)**: Native mobile push notifications.
* [ ] **Postman**: API collection tester.

### 5. Strategy & Management
* [ ] **Notion** or **Linear**: For tracking sprints, Epics, and managing bugs.
* [ ] **Figma**: Screen designs, component libraries, and assets.
* [ ] **n8n**: For building low-code webhook workflows (e.g. sync leads to CRM).

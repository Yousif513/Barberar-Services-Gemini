# MVP Build Plan

This document defines the functional deliverables for each portal of the marketplace MVP, prioritizing features based on the MoSCoW framework.

---

## 1. Website MVP (B2C & Provider Acquisition)
The primary role of the website is consumer discovery and B2B lead capture.

### Must Have (Phase 1)
* **SEO Landing Page**: High-conversion landing page detailing Men's & Women's services.
* **Service Provider Lead Form**: Onboarding application form for Salons and Freelancers.
* **Responsive Search Panel**: Simple zip/district-based search interface for consumers.
* **Bilingual Support (AR/EN)**: Instant locale translation button.

### Should Have
* **Web Booking widget**: Embeddable booking iframe that providers can paste into their own websites.
* **Interactive Map**: Display partner salon coordinates.

### Could Have
* **Direct Web Booking Flow**: Full booking and payment checkout directly via mobile browser.

---

## 2. Mobile App MVP (B2C Customers)
The core client experience is mobile-first, designed for native iOS & Android.

### Must Have (Phase 1)
* **WhatsApp OTP Sign-In**: Authentication using mobile phone number.
* **Discovery Search Feed**: GPS geolocated listing of nearby providers, filtered by rating, service, and availability.
* **Interactive Checkout**: Secure payment processing (Mada, Apple Pay) for upfront booking deposits.
* **Appointment Tracker**: Screen showing active, past, and cancelled bookings with real-time status.

### Should Have
* **Home Service Real-Time Tracking**: GPS tracking on a map to see the home service provider's route.
* **In-App Messaging**: Text chat between client and provider for service details.

### Could Have
* **Loyalty Hub**: Virtual card showing points balance and rewards milestones.

---

## 3. Provider Dashboard MVP (Salons & Freelancers)
A dual-purpose portal enabling providers to manage their operational and financial lifecycles.

### Must Have (Phase 1)
* **Multi-Branch calendar**: Schedule grid allowing managers to view and edit shifts for multiple staff members.
* **Service Menu Builder**: Create services, set default durations, base prices, and category tags.
* **Deposit Enforcer**: Configurable setting to require a deposit (20%-100%) during customer checkout.
* **Wallet Balance & Cash Ledger**: Display online payments, accrued platform fees, and cash receipts.

### Should Have
* **Shift Templates**: Pre-configured weekly shifts (e.g. Morning, Evening, Off-duty).
* **Automatic Commission calculations**: Split transaction details per employee.

### Could Have
* **SMS/WhatsApp Client Broadcast**: Send discount promo codes directly to past clients.

---

## 4. Admin Dashboard MVP (Platform Managers)
The operational control center of the marketplace.

### Must Have (Phase 1)
* **Verification Checklist Panel**: Approve or reject salon commercial registrations and freelance permits.
* **Global System Categories Editor**: Create and arrange marketplace service taxonomies.
* **Escrow Ledger & Manual Payout Trigger**: View captured deposits, platform fees, and trigger weekly bank transfers.
* **Dispute and Refund Manager**: Process partial/full customer refunds on cancelled bookings.

### Should Have
* **System Health Monitor**: Alerts when API gateways experience high latency.

### Could Have
* **Commission Rate Override Panel**: Customize platform commission rates for select premium salons.

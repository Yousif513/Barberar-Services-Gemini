## 1. Branching & Co-Working Protocol

To ensure models do not overwrite or conflict with each other's active work, we adhere to the following branch isolation guidelines:

### Model-Specific Branches
* **Claude Code**: Works on the **`claude-code`** branch.
* **Gemini (Antigravity)**: Works on the **`gemini`** branch.
* **Codex / Cursor (User Direct)**: Works on the branch of the active feature or `master`.

### Protocol Steps (Before starting any task)
1. **Check Branch (do NOT switch)**: Run `git status` to see the active branch. **Work on whatever branch is already checked out.** The human drives branch selection.
2. **Check for Uncommitted Changes**: Run `git status` to confirm there are no uncommitted changes from another model before modifying files. If there are, leave them untouched.
3. **Stay in sync via this changelog**: Read the latest entries below to see what other agents touched, and avoid heavy rewrites of files another agent changed recently.

### 🔒 Golden Rules (MANDATORY — these override the branch-per-agent guidance above)
> Added 2026-06-19 after a coworking incident: an agent switched branches (`git checkout`), which swapped the working tree to another branch's files and *looked* like work was deleted. Nothing was lost, but it disrupted the human. To prevent recurrence:
1. **NEVER switch the active branch or rewrite history.** Do not run `git checkout <branch>` / `git switch`, `git reset --hard`, `git rebase`, force-push, or cross-branch `git cherry-pick`. Branch management is the human's job — commit on the branch that is already checked out.
2. **NEVER overwrite another agent's files.** Use small, targeted edits. If a file appears in another agent's recent changelog entry, coordinate before touching it heavily.
3. **Commit on the active branch** with clear agent attribution and append a changelog entry. **Do not push another agent's branch** unless the human asks.
4. **To move work between branches, ASK THE HUMAN.** Never merge or cherry-pick across agent branches on your own.
5. **If you discover you are on a different branch than expected, STOP and tell the human — do not "fix" it by switching.**

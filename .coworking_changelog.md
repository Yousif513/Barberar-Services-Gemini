## 1. Branching & Co-Working Protocol

To ensure models do not overwrite or conflict with each other's active work, we adhere to the following branch isolation guidelines:

### Model-Specific Branches
* **Claude Code**: Works on the **`claude-code`** branch.
* **Gemini (Antigravity)**: Works on the **`gemini`** branch.
* **Codex / Cursor (User Direct)**: Works on the branch of the active feature or `master`.

### Protocol Steps (Before starting any task)
1. **Check Branch**: Immediately run `git branch` or `git status` to verify the active branch.
2. **Switch if necessary**:
   * If you are Claude Code: Switch to the Claude branch: `git checkout claude-code`
   * If you are Gemini: Switch to the Gemini branch: `git checkout gemini`
3. **Check for Uncommitted Changes**: Run `git status` and `git diff` to make sure there are no uncommitted changes from another model before modifying files.
4. **Sync with Master**: Pull the latest stable changes: `git pull origin master` or merge `master` into your active branch.

## Local booking and support pilot behavior

- Select a language without losing selections or local identifiers.
- Import a public source catalog through a validation preview and explicit confirmation.
- Search the imported sources; show an empty result or source error honestly.
- Select source service, staff and requested Riyadh date/time.
- Review an immutable source snapshot and confirm a local request.
- Open an existing local request and its append-only history.
- Record a local support/refund case through an explicit reason/evidence confirmation.
- Append a case note or appeal using its current revision.
- External booking, payment and business support dispatch remain held terminal states, with no outgoing action.

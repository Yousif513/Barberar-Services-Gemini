# primora-design-system - PROPOSED

This is version 0.1.0-proposed, a staged replacement for an unrecovered original. It does not establish approval. Read [proposal provenance](references/proposal-source.md).

Use the approved current project theme when available. Distinguish inherited brand tokens from new choices; keep one approved theme across tasks, decisions, profiles and evidence. Gold is an accent; prefer ink on ivory and soft gold on obsidian for readable text. Recompute contrast when changing a pair. Preserve existing English fallback fonts and IBM Plex Sans Arabic behavior; verify actual font delivery before acceptance.

Specify shared navigation, fields, status/evidence badges, citations, tables, decision receipts and component states. Mirror Arabic with logical properties and direction-aware icons; isolate numbers, URLs and IDs. Label inactive, proposed, blocked and unknown distinctly. No fabricated portraits, presence, metrics or success receipts. Instruction presence is not competence or authority.

In planning, produce source/token/component contracts and unresolved evidence only. Screen generation/build requires CEO-approved scope/theme. Later acceptance must exercise AR/EN/RTL, keyboard/focus, responsive layouts and contrast; a token ratio is not a browser audit.

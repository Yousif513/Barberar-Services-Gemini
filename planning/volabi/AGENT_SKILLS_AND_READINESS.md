All 42 functions remain proposed records, not 42 continuously running sessions. Later six-manager studies do not replace this roster.

Profile sections: charter/source; assigned/proposed skills; required versions and exact provenance/hash; missing capabilities; structural validation and independent behavioral evidence separately; evidence freshness; tools, prerequisites and actual permission status separately; task-specific readiness; skill-change recommendations; evaluation/binding history.

Absent source versions are shown as not declared with a content hash, never silently labelled latest. Evidence is scoped to tested skill/model/agent version, task, environment and tools. A file check is not an executed skill evaluation. Freshness displays actual observation time; an unapproved validity duration remains unset.

Composer requirements drive the matrix: required capability/skill/version, source, output/acceptance, owner/reviewer, tools/data scope and limits. Each dimension is met/missing/failed/unknown. Overall assessment is ready-for-CEO-review, needs-evidence, blocked-prerequisite or inactive-for-execution with exact reasons. No invented competence percentage. Proposed alternatives require evidence of equivalence. Changing requirements, versions, source evidence or authority invalidates the older assessment.

Changes: proposed -> source/version diff and affected tasks -> bounded evaluation proposal -> awaiting CEO -> approved/declined/changes-requested/expired/revoked -> checked binding receipt. Evaluation approval authorizes only named resources; adoption does not activate an employee or grant business access. Preserve removed bindings in history and assess queued work before applying a revision.

Evaluation details identify category (structural validation/static review/synthetic behavior/isolated integration/live acceptance), exact inputs and observed result, evidence/hash, date, environment, versions, reviewer, limitations and supersession. Unreadable/absent evidence remains unknown. The current profile JSON establishes source/file presence only; it does not certify HQ task performance.

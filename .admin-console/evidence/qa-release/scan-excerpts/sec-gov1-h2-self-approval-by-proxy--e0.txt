    1: -- GOV-FIX H-2 and M-4 (docs/reviews/2026-10-10-security-gov1.md): no self-approval by proxy, and no self-review.
    2: --
    3: -- H-2. An owner could make an account they control finance (admin_set_console_role took effect at once) and approve their own
    4: -- payouts, refunds and IBAN changes from it, or demote every other approver to unlock break-glass. The report's fix:
    5: --   1. A role change that ADDS a privileged permission (money.*, iban.*, roles.manage, mfa.reset, settings.manage,
    6: --      alerts.acknowledge, break_glass.*, rewards.approve, health.break_glass) is a governance request ('role_change') that a
    7: --      different owner approves. Break-glass never applies to it, so a sole owner cannot add approvers alone.
    8: --      Changes that add nothing privileged (to analyst or operations, owner -> finance, removal) still apply at once:
    9: --      taking power away must stay fast.
   10: --   2. A newly granted approver decides no request for 72 hours (admin_role_assignments.decisions_allowed_from).
   11: --   3. A decision is refused when the decider's console role was assigned by the requester within the last 30 days.
   12: --   4. Break-glass is refused for 7 days after any administrator who could have approved that kind of request was demoted
   13: --      or removed (admin_role_history, written by a trigger on every assignment change, whoever makes it).
   14: -- M-4. The owner who used break-glass cannot record its independent review, and nobody acknowledges a security alert about
   15: --      themselves or about an action they took.

   17: DROP FUNCTION IF EXISTS pg_temp.patch_function(regprocedure, text, text);
   18: CREATE OR REPLACE FUNCTION pg_temp.patch_function(p_sig regprocedure, p_from text, p_to text) RETURNS void LANGUAGE plpgsql AS $patch$
   19: DECLARE v_def text := replace(pg_get_functiondef(p_sig), E'\r\n', E'\n');
   20: BEGIN
   21:   p_from := replace(p_from, E'\r\n', E'\n'); p_to := replace(p_to, E'\r\n', E'\n');
   22:   IF position(p_from IN v_def) = 0 THEN RAISE EXCEPTION 'patch_function: pattern not found in %', p_sig; END IF;
   23:   EXECUTE replace(v_def, p_from, p_to);
   24: END $patch$;
